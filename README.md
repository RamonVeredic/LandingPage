# LandingPage

LandingPage adalah repositori yang menyediakan berbagai template landing page gratis yang siap digunakan untuk kebutuhan bisnis, startup, portofolio, produk, dan campaign marketing.

Dengan desain yang modern, responsif, dan mudah dikustomisasi, repositori ini cocok untuk developer, freelancer, maupun pemilik bisnis yang ingin membuat website promosi dengan cepat tanpa harus memulai dari nol.

## Fitur

- Template landing page gratis dan siap pakai
- Desain modern dan responsif
- Struktur HTML/CSS/JS yang mudah dimodifikasi
- Cocok untuk produk, bisnis, startup, portfolio, dan landing page campaign
- Mudah disesuaikan dengan kebutuhan branding dan konten
- Dapat dijadikan referensi atau starter project untuk pengembangan website

## Daftar Template

Berikut contoh kategori template yang dapat Anda tambahkan atau kembangkan di repositori ini:

- SaaS Landing Page
- Startup Product Page
- Business Company Profile
- Portfolio Landing Page
- App Product Promo Page
- Agency / Studio Landing Page
- Event / Conference Landing Page
- Restaurant / Cafe Promo Page

## Struktur Repository

```bash
LandingPage/
├── README.md
├── assets/
├── css/
├── js/
├── images/
├── index.html
└── templates/
```

Catatan:
- `index.html` merupakan halaman utama template
- `css/` berisi file styling
- `js/` berisi script interaktif
- `assets/` atau `images/` berisi aset visual seperti logo, ikon, dan gambar latar
- `templates/` dapat digunakan untuk menampung berbagai layout landing page yang berbeda

## Cara Menggunakan

1. Clone repository ini:

```bash
git clone https://github.com/plannethost/LandingPage.git
```

2. Masuk ke direktori project:

```bash
cd LandingPage
```

3. Buka file `index.html` di browser atau jalankan local server favorit Anda.

4. Sesuaikan teks, warna, gambar, dan konten sesuai kebutuhan brand atau bisnis Anda.

## Cara Menyesuaikan Template
